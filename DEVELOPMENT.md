# РАЗВЁРТЫВАНИЕ И ИНСТРУКЦИИ

## 1. ЛОКАЛЬНАЯ РАЗРАБОТКА

### Запуск в разработке

```bash
cd timesushist
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`

### Основные команды

```bash
# Разработка
npm run dev

# Проверка типов
npm run build   # Проверяет TypeScript без создания dist/

# Просмотр лучших практик
npm run lint    # (не настроено, но можно добавить)
```

## 3. ОСНОВНЫЕ ВОЗМОЖНОСТИ

### ✅ Реализовано

- **Календарь смен** — интерактивный календарь с отображением смен
- **Быстрое добавление смен** — модальное окно редактора с автоматическими расчётами
- **Автоматический расчёт заработка** — точные вычисления с поддержкой дробных ставок

- **Учёт выплат** — отслеживание полученных денег и остатков
- **Статистика и графики** — визуализация данных (LineChart, BarChart, PieChart)
- **Настройки** — выбор валюты, ставки, формата даты, темы
- **Локальное хранилище** — все данные сохраняются в localStorage
- **Нижняя навигация** — 4 основных раздела (Календарь, Периоды, Выплаты, Статистика)
- **Интеграция с Telegram** — поддержка Telegram WebApp SDK
- **Русский интерфейс** — полностью на русском языке

- **Supabase** — структура БД и RLS политики документированы в README

## 4. ФИНАНСОВЫЕ РАСЧЁТЫ

Все расчёты выполняются с высокой точностью:

```javascript
// Отработанные часы
часы + минуты / 60

// Базовый заработок
часы × ставка

// Дополнительные ставки
часы_доп × ставка × коэффициент + фиксированная

// Итого за смену
базовый + дополнительные + премии - удержания

// Остаток к получению
начислено - получено

// Итоговое округление: до 2 знаков после запятой
```

Промежуточные вычисления НЕ округляются - только итоги.

```javascript
localStorage.getItem('timesushist_settings')

//   currency: 'PLN',
//   date_format: 'DD.MM.YYYY',
//   theme: 'light'
// }
```

### Переход на Supabase

Все компоненты уже готовы к замене localStorage на Supabase:

1. Обновить `useDataStore.ts` — заменить localStorage на Supabase API
2. Добавить Supabase Auth — использовать Telegram initData для проверки
3. Включить Row Level Security — пользователи видят только свои данные
4. Добавить в `.env.local`:
   ```
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your-anon-key
   ```

## 8. РЕКОМЕНДАЦИИ ПО ДАЛЬНЕЙШЕЙ РАЗРАБОТКЕ

### Срочное

1. **Исправить сборку Vite** — проблема с PostCSS/Tailwind в v8 Vite
   - Решение: вернуться на Vite v5 или настроить PostCSS правильно
   - Для продакшена: `npm run build` должен работать без ошибок

2. **Подключить Supabase** — все готово, только нужно обновить `useDataStore.ts`

3. **Добавить Telegram Auth** — проверка initData на backend

### Рекомендуемое

1. **Импорт/Экспорт данных** — CSV, JSON
2. **Шаблоны смен** — быстрое заполнение графика
3. **Push-уведомления** — напоминания о смене
4. **Оффлайн-режим** — работа без интернета
5. **Тёмная тема** — готов конфиг, нужно активировать

### Оптимизация

1. **Кеширование** — TanStack Query для синхронизации с сервером
2. **Виртуализация** — для больших списков смен
3. **Lazy Loading** — отдельная загрузка графиков
4. **PWA** — установка как приложение

## 9. РЕШЕНИЕ ПРОБЛЕМ

### Приложение не загружается

```bash
# Очистить node_modules и переустановить
rm -rf node_modules
npm install
npm run dev
```

### Ошибки TypeScript

```bash
# Проверить типы без сборки
npm run build  # (просто проверяет)
```

### Данные не сохраняются

1. Проверить, включен ли localStorage в браузере
2. Проверить DevTools → Application → Local Storage
3. Очистить localStorage: `localStorage.clear()`

### Построение для продакшена

```bash
# Текущее состояние: нужно исправить Vite конфиг
npm run build

# Временное решение: использовать dev версию
npm run dev -- --outDir dist
```
